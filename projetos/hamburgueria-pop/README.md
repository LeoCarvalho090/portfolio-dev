# Hamburgueria · Pop — website demonstrativo

Uma interface de restaurante com identidade **retrô e vibrante**, construída para explorar contraste, composição visual e experiência de navegação.

## Implementação

- Layout adaptável a telas pequenas e grandes.
- Menu de navegação e componentes interativos em JavaScript.
- **Carrinho demonstrativo** com atualização local de itens e valores.
- Elementos gráficos vetoriais criados para o conceito.

**Tecnologias:** HTML, CSS, JavaScript e SVG.

## Escopo

O carrinho não efetua pagamentos nem envia pedidos. Produtos, preços e identidade do estabelecimento são fictícios.
