# Academia · Energia — website demonstrativo

Uma alternativa de landing page para academia, com **paleta carvão e laranja**, comunicação direta e foco na apresentação de modalidades e planos.

## O que foi desenvolvido

- Estrutura de página responsiva para divulgação de um estabelecimento esportivo.
- Hierarquia visual com chamadas para ação, modalidades e diferenciais.
- Três modalidades de planos ilustrativos: mensal, semestral e anual.
- Interações de navegação implementadas em JavaScript, sem dependência de backend.

**Tecnologias:** HTML, CSS e JavaScript.

## Escopo

O nome do estabelecimento, os valores e as informações de contato são fictícios. O website é um **conceito de interface**, não a página de uma academia real nem um sistema de matrícula.
