# Barbearia · Editorial — website demonstrativo

Este conceito explora uma linguagem visual mais editorial, com **tipografia expressiva, composição espaçosa e uma paleta de creme, oliva e terracota**.

## Implementação

- Layout responsivo para apresentação de serviços e posicionamento de marca.
- Navegação em dispositivos móveis.
- Interações demonstrativas de interface e modal, implementadas em JavaScript.
- Ilustração vetorial local, sem necessidade de imagem externa na área principal.

**Tecnologias:** HTML, CSS, JavaScript e SVG.

## Escopo

Marca, horários, serviços e contatos são ilustrativos. O fluxo de agendamento é demonstrativo e **não confirma horários nem envia mensagens**.
