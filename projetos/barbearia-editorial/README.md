# Modelo 06 — Sua Barbearia (Editorial)

Layout editorial creme + verde-oliva + terracota. Site estático 100% independente.

## Arquivos
- `index.html` — página principal
- `assets/css/styles.css` — cores e layout
- `assets/js/main.js` — menu e modal demonstrativo
- `assets/img/hero.svg` — ilustração original, sem imagem externa

Acesse pelo hub local. Nomes, serviços, valores e horários são ilustrativos.
**O botão de agendamento não envia mensagens reais.** Para entregar a um cliente, substitua identidade, informações, imagens e configure contato autorizado.
