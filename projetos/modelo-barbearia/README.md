# Barbearia · Clássico — website demonstrativo

Website de página única com **identidade escura, detalhes dourados e apresentação de serviços**, pensado como exercício de direção visual e implementação responsiva.

## Implementação

- Estrutura semântica em HTML e estilos responsivos em CSS.
- Navegação móvel e atualização dinâmica de informações configuráveis em JavaScript.
- Seções de serviços, galeria e contato.
- Integração de WhatsApp preparada para um número autorizado; na demonstração, há aviso em vez de envio real.
- Tratamento visual para falhas no carregamento de fotografias externas.

## Decisões técnicas

O conteúdo essencial permanece acessível em uma página estática. A camada JavaScript controla apenas interações e configurações simples; não há backend, banco de dados ou calendário de agendamentos.

## Escopo e fontes de imagem

A barbearia é fictícia. Serviços, preços, horários e dados comerciais são ilustrativos. Algumas fotografias de referência são externas e dependem de conectividade e das respectivas condições de licenciamento.
