# Academia · Performance — website demonstrativo

Landing page voltada à apresentação de uma academia fictícia. O conceito combina **identidade visual esportiva, planos, modalidades e informações de contato** em uma navegação responsiva.

## Implementação

- Seções de modalidades, diferenciais, planos, horários e perguntas frequentes.
- Componentes adaptados para celular e tablet.
- Ilustrações SVG locais, com boa apresentação mesmo sem fotografias externas.
- Links de WhatsApp preparados para receber um contato autorizado. Sem número configurado, o visitante recebe um aviso de demonstração.
- HTML, CSS e JavaScript sem framework obrigatório.

## Decisões de interface

As informações comerciais foram organizadas para tornar planos e modalidades fáceis de comparar. O menu móvel e as chamadas para ação foram desenvolvidos com foco em clareza e consistência visual.

## Escopo

**Não há matrícula ou agendamento real.** Marca, valores, horários e serviços são ilustrativos. O código contém um ponto de configuração de contato, mas nenhuma mensagem é enviada pela demonstração.
